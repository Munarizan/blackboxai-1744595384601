# SRAR Solatiah

## Project Overview
SRAR Solatiah is a web application designed to provide vital information about the school's organizational structure, class lists, fee structures, and a payment form for school fees. The application is built using HTML and styled with Tailwind CSS, providing a responsive and user-friendly interface.

## Installation
To get started with SRAR Solatiah, follow these steps:

1. Clone the repository to your local machine:
   ```bash
   git clone <repository_url>
   ```

2. Navigate to the project directory:
   ```bash
   cd srar-solatiah
   ```

3. Open the `index.html` file in your web browser to view the application.

No additional dependencies are required as the project primarily utilizes CDN links for external CSS and JavaScript resources.

## Usage
Open the `index.html` (or any other final HTML version such as `final_index.html` or `final_index_v2.html`) in your preferred web browser. You will find:

- An **Organizational Chart** depicting the school's hierarchy.
- A **Class List** section displaying available classes.
- A **Fees Structure** section detailing tuition fees and others.
- A **Payment Form** where you can enter details and upload payment slips.

## Features
- Responsive design using Tailwind CSS.
- Organized layout showcasing school structure, classes, and fee breakdown.
- A user-friendly payment form for submitting school fees.

## Dependencies
The project relies on the following external libraries and frameworks:
- [Tailwind CSS](https://tailwindcss.com/) - For styling and layout.
- [Google Fonts](https://fonts.googleapis.com) - Specifically the Poppins font family.
- [Font Awesome](https://fontawesome.com/) - For icons used throughout the application.

## Project Structure
The project consists of the following main files:

```
/srar-solatiah
│
├── index.html            # Initial version of the application
├── updated_index.html    # Updated version with some enhancements
├── final_index.html      # Final version before v2 timeline

```

Each HTML file serves as a standalone webpage, allowing for easy navigation and viewing of the content related to the school.
